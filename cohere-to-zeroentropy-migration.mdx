# Migrating from Cohere to ZeroEntropy

This guide provides a detailed procedure for migrating your AI applications from **Cohere** to **ZeroEntropy** and explains why **ZeroEntropy** is advantageous.

## Overview

Although **Cohere** and **ZeroEntropy** share conceptual similarities for rerankers and embeddings. **ZeroEntropy** offers faster throughput, improved latency (up to 12% faster in benchmarks), and typed Python SDKs for safer integration.

Here are some of the benefits of switching to **ZeroEntropy**:

- **Faster Response Times:** ZeroEntropy offers up to 12% improved latency in reranking tasks compared to Cohere, making your applications more responsive.
- **Typed SDK & Strong Typing:** ZeroEntropy's Python SDK uses typed Pydantic models, ensuring safer and clearer code with better autocomplete and validation.
- **Optimized Models:** ZeroEntropy models like `zerank-1` and `zenbed-1` are specifically tuned for fast and accurate reranking and embeddings across domains (legal, healthcare, etc.).
- **Better Scalability:** Async support allows high concurrency and throughput for large-scale applications.
- **Secure API Key Management:** Environment variable configuration reduces the risk of accidentally exposing keys in code.

## Prerequisites

<Card title="ZeroEntropy Requirements" icon="shield-check">
  - Python 3.8 or later
  - Existing Cohere integration (typically using `cohere`package for rerank/generate APIs)

  **Important:** Store this key securely; you will use it in API requests.
</Card>

1. Launch the [Zentropy](https://www.zeroentropy.dev/) portal.

   ![Home Page Pn](/images/home-page.png)

2. You can choose to add your API keys in any of the following ways:
   - In the portal, click either the  **Dashboard** or the **Start Now** button at the top-right corner of the screen.
   - In the portal, click the **Get API Key** button at the bottom-left corner of the screen.

     **Result:** The **API Keys page** appears:

     ![Api Keys Page Pn](/images/api-keys-page.png)
3. In the API Keys page, click the **\+ Add API Key** button. The **Add API** dialog appears:

  ![Add Api Key Pn](/images/add-api-key.png)

3. Enter a suitable name as required in the API key name in the **API Key Name** box.
4. By default, the **Permission Level** is set to _Read Only_. To change the **Permission Level** to _All Permissions_, click the **Permission Level** pulldown button and change the permission level.
5. Click the **Create API Key** button. The API key is created and appears in the **Organization API Keys** table list.
6. Update your current Cohere API integration key in your Python code. For example:

```python
from cohere import Client
cohere_client = Client('YOUR_COHERE_API_KEY')
response = cohere_client.rerank(
    model='rerank-3.5',
    query='Your search query', 
    documents=['Doc 1', 'Doc 2', 'Doc 3']
print(response)
```

 to this:

```python
from zeroentropy import ZeroEntropy

zclient = ZeroEntropy(api_key='YOUR_ZEROENTROPY_API_KEY')

response = zclient.models.rerank(
    model='zerank-1',
    query='Your search query',
    documents=['Doc 1', 'Doc 2', 'Doc 3']
)
print(response.model_dump_json(indent=4))
```

8. Replace all endpoint URLs and model names to use ZeroEntropy's API. Check for version-specific parameters; ZeroEntropy supports `zerank-1` and `zerank-1-small`.

> <Tip>
>   > Review ZeroEntropy's documentation for additional features like latency optimization and payload sizes.
> </Tip>

Following these steps, you can smoothly transition from Cohere to ZeroEntropy, unlocking faster query performance and cost efficiencies with minimal code changes.
